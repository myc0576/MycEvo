# Cursor Integration Recipe

Status: **L0 portable recipe.** This is not advertised as a tested native Cursor adapter.

1. Keep task contract, corrections, evidence and closeout artifacts inside the selected MycEvo workspace.
2. Ask Cursor to read the workspace `AGENTS.md`/contract before editing.
3. Use `mycevo demo`, `mycevo intake`, or the portable file protocol to create a candidate.
4. Do not treat an Agent-generated candidate as canonical without a human decision.

When an executable Cursor integration and automated test exist, this document may be upgraded to L1.
