# MycEvo 0.2.0 Technical Preview — Unreleased

MycEvo 0.2.0 is being prepared as a source-available technical preview for people who use multiple coding/research Agents and need durable, reviewable workflow memory.

## Proven now

- isolated local workspace initialization;
- deterministic candidate-first demo;
- provenance and guarded evaluation primitives;
- Codex/Claude MCP configuration dry-runs;
- explicit prevention of automatic canonical promotion;
- default-deny public release staging.

## Not claimed yet

- a complete standalone human decision/canonical lifecycle;
- complete handoff, rollback, import, export and deletion APIs;
- native event capture from every Agent;
- Team collaboration, RBAC, sync or shared canonical state.

## Release blockers

- G1 license, rights, dependency and contribution authorization;
- clean staging package/fresh-install evidence;
- owner approval for updating the already-public MycEvo repository.
