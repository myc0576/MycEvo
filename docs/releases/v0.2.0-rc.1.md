# MycEvo v0.2.0-rc.1 — PaperFrames Engineering Runtime Preview

## Verified

- MycEvo constrained plugin governance and provenance chain
- Docling → PaperFrames IR → Typst → PDF golden path
- Corpus Factory metadata workflow with private-provider no-upload boundary
- Shortcraft candidate schema, validation CLI and human-gated candidate state
- Synthetic public fixtures and reproducible tests

## Experimental

- Complex real-world paper extraction
- External corpus providers beyond metadata discovery
- Automatic mining and candidate generation

## Contract-only

PyVista, ParaView, FreeCAD, GROBID and LaTeX adapters remain contract-only or
planned. They are not production-ready.

## Known limitations

Docling has a substantial optional runtime; Typst is an external CLI; a
successful execution is not scientific validation; private corpora are not
part of the public repository; and candidate cards are not curated claims.

This release does not publish to PyPI, Docker, Marketplace or any production
package registry.
