# Contributing to MycEvo

MycEvo is in a source-available technical-preview phase.

## Welcome now

- reproducibility reports;
- design and release-contract feedback;
- adapter, pack and workflow proposals;
- Issues and Discussions;
- non-substantive documentation corrections that do not introduce third-party content.

## Temporarily blocked

Do not submit substantive code PRs until the owner/legal G1 gate approves a contributor-license agreement and the repository records signed acceptance. This protects both contributors and the project's ability to offer consistent source-available and commercial licensing.

`CONTRIBUTOR_LICENSE_AGREEMENT.CANDIDATE.md` records the selected agreement shape; it is not active yet.

## Contribution rules

- never submit private prompts, data, traces, credentials or customer material;
- add tests for behavior changes;
- preserve candidate-first and human-only promotion;
- label capture completeness as L0, L1 or L2;
- do not describe MycEvo as OSI open source;
- disclose copied/adapted third-party material and its license.
